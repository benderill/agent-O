Take the dilution problem to Ax

You tuned this by hand in the simulator. Here is the same problem as code you could point at a physical lab, built on Ax and BoTorch. The script starts from Honegumi and runs in Colab with one click.

1. What maps to what

In this siteIn Ax
Water (ml), 0 to 30A range parameter water with bounds 0 and 30
Color difference ΔE, minimizedAn objective delta_e with minimize=True
Surrogate and acquisition pickerChosen by Ax automatically: a few quasi-random (Sobol) trials, then a Gaussian process with BoTorch. You can override it.
Mix budget (8)Number of trials in the loop, N_TRIALS = 8
The pipette and camerameasure_delta_e(water). Here it is the same simulated color model as the site. In a real lab, replace it with your measurement.

3. Change the setup in Honegumi

Honegumi is a grid of options. Flip a switch and it writes the matching Ax code. This script was generated with the settings below. To add a constraint, a second objective or batches, change them on Honegumi's page and redo the edits marked MOD.

  • Objective: single
  • Model: default
  • Task: single
  • Categorical parameter: no
  • Constraints: none
  • Existing data: no
  • Synchrony: single
